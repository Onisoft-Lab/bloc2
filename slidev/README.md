# Soutenance VéloVille

Support Slidev de l’oral (20 minutes de présentation, puis les questions). Les notes du présentateur suivent l’ordre imposé par le sujet.

```bash
cd temp/livrables/slidev
npm install
npm run dev
```

Mode présentateur : [http://localhost:3030/presenter](http://localhost:3030/presenter). Les notes ne s’affichent pas sur l’écran projeté.

PDF, si besoin du fichier à déposer :

```bash
npm run export
```
